# Crossroads Google Form Automations

This repository contains Google Apps Script projects that automate Crossroads form submissions with Google Forms, Sheets, Drive, Docs, Gmail, and Telegram.

## Current projects

### [Spiritual Gifts & Personality Assessment](./Spiritual%20Gifts%20%26%20Personality%20Assessment/)

Processes 112 Spiritual Gifts questions and 24 DISC questions after submission. It calculates gift rankings and DISC scores, creates a detailed DOCX report in Google Drive, updates the response spreadsheet, emails the participant, and sends a Telegram summary.

See [application flow](./Spiritual%20Gifts%20%26%20Personality%20Assessment/description.md).

### [The Crossroads Dormitory Application Form 2026–2027](./The%20Crossroads%20%20Dormitory%20Application%20Form%202026-2027/)

Processes dormitory applications submitted through Google Forms. It generates a candidate ID and candidate folder, creates a Google Document and PDF, optionally includes the applicant photo, notifies staff through Telegram, and records document links and status in Google Sheets.

See [application flow](./The%20Crossroads%20%20Dormitory%20Application%20Form%202026-2027/description.md).
